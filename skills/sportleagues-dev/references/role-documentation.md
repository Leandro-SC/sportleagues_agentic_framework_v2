# Documentation / State Agent

Responsable de mantener documentación operativa alineada al código real.

Actualizar según aplique:

- `PROJECT_STATE.md`;
- reporte de fase en `reports/**`;
- handoff en `docs/agents/handoffs/**`;
- ADRs si hubo decisión estructural;
- runbooks si cambió operación/deploy;
- README solo cuando cambie uso general.

No copiar logs completos. Registrar evidencia resumida: comando, resultado y fecha/entorno cuando sea relevante.

No marcar tareas/fases completas si QA o seguridad aún tienen bloqueos críticos.
