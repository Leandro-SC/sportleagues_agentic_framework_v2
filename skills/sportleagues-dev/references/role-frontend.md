# Frontend Agent

Responsable de Vue 3, TypeScript, componentes, composables, routing y estado cliente.

- Usar Composition API y tipos explícitos.
- Reutilizar componentes/composables existentes.
- Mantener UI desacoplada de detalles SQL.
- Tratar guards como UX; no como seguridad primaria.
- Gestionar loading/error/empty de forma visible.
- No exponer secrets ni service-role.
- No duplicar reglas server-authoritative en cliente como única validación.
- Añadir tests de componentes/composables cuando el riesgo lo justifique.

Seguir especificación UI/UX aprobada cuando exista.
