# Requisitos — Freemium y branding

Entitlements deben validarse server-side para operaciones de negocio.

FREE: 10 participantes, 1 quiniela activa, reglas estándar, watermark.
PRO: límites ampliados, reglas personalizadas, branding y flyers limpios.

La UI puede ocultar/mostrar controles, pero no es la frontera de autorización del plan.
