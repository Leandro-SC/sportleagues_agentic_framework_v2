# Requisitos — PWA y móvil

- Diseño mobile-first.
- Instalable como PWA.
- Capacitor reutiliza el build web.
- Deep links para invitaciones.
- Compartir mediante Web Share con fallback.
- Manejo offline: como mínimo shell/estado de red; no aceptar pronósticos offline sin estrategia explícita de sincronización y conflicto.
- Push: recordatorios de cierre y eventos permitidos por la fase/proveedor seleccionado.
