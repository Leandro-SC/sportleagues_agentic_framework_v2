# Referencias funcionales del proyecto de quiniela anterior

Estos archivos son copias de **lectura** (`.php.txt`) aportadas por el usuario. No se ejecutan, importan ni despliegan. Sirven para estudiar tickets, gestión de jornadas, rankings y flujo administrativo antes de implementar equivalentes seguros en Vue + Supabase.

**No está incluido el ZIP original** ni `.env`, `.git`, bases de datos, configuraciones, secretos ni archivos de despliegue. No trasladar consultas PHP o autorizaciones del sistema antiguo a producción. Verificar derechos/licencias de cualquier asset externo antes de reutilizarlo.
